# Screenshots

The images here are used by the main [`README.md`](../../README.md).

## Current images

The PNGs in this folder are **placeholder screenshots** generated by
[`generate_placeholders.py`](./generate_placeholders.py). They keep the README
layout intact and will be replaced with real app screenshots once the frontend
can be rendered reliably in this Windows environment (the local Next.js dev
server currently hits an `EBUSY` file-lock issue).

## Generate placeholders

```bash
cd ../../backend
venv/Scripts/python ../docs/screenshots/generate_placeholders.py
```

## Replace with real screenshots

1. Start the backend and frontend.
2. Use Playwright (already installed in `frontend`) or any screenshot tool to
capture the following pages at 800×450 (or larger):
   - `/login`
   - `/documents`
   - `/upload`
   - `/chat`
   - `/dashboard`
   - `/evaluate`
3. Overwrite the PNGs in this folder and remove this README note.
